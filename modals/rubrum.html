Rubrum

Plataforma web Sass completa para gerenciamento de embalagens, permitindo todo o controle centralizado, rastreamento e organização em toda a cadeia de produção.

O sistema oferece uma interface intuitiva para cadastro, consulta e acompanhamento do desenvolvimento das embalagens em tempo real.

Tecnologias / ferramentas / bibliotecas utilizadas:

  • HTML5
  • Compilador LESS
  • CSS3
  • Javascript
  • Angular JS
  • Laravel 5
