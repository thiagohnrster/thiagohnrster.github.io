Rubrum - Site Comercial V2Em desenvolvimento

Redesign completo do site comercial da plataforma Rubrum, sistema de gerenciamento de embalagens. O projeto apresenta uma nova identidade visual com foco em clareza, modernidade e conversão, comunicando de forma objetiva os diferenciais da plataforma para o público-alvo.

Tecnologias / ferramentas / bibliotecas utilizadas:

  • HTML5
  • Compilador LESS
  • CSS3
  • Javascript
  • GSAP
  • jQuery
