HDC EventosEm desenvolvimento

Plataforma web para gerenciamento e divulgação de eventos, permitindo a criação, organização e acompanhamento de eventos de forma centralizada. O sistema oferece recursos para cadastro de eventos, gerenciamento de participantes, exibição de informações detalhadas e integração entre organizadores e usuários.

Tecnologias / ferramentas / bibliotecas utilizadas:

  • HTML5
  • Sass
  • Javascript
  • Angular JS
  • Laravel 5
  • PHP
