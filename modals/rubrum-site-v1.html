Rubrum - Site Comercial V1

Primeiro site comercial desenvolvido para divulgar a plataforma Rubrum, sistema de gerenciamento de embalagens. O projeto estabeleceu a presença digital da plataforma, apresentando suas funcionalidades e diferenciais de forma acessível para potenciais clientes.

Tecnologias / ferramentas / bibliotecas utilizadas:

  • HTML5
  • Compilador LESS
  • CSS3
  • Javascript
  • jQuery
